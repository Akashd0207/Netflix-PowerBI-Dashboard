# Netflix Power BI Dashboard

## Overview
This project analyzes Netflix content using Power BI to uncover trends in movies, TV shows, genres, and ratings.

---

## Key Insights
- Total Movies vs TV Shows distribution
- Content growth over years
- Most popular genres
- Rating distribution of content
- Trends in Netflix content strategy

## Tools Used
- Power BI
- Power Query (M)
- DAX

## Features
- Track total content (Movies vs TV Shows)
- Analyze content growth over the years
- Identify most common genres on Netflix
- Understand rating distribution across content
- Explore how content type has changed over time
- Break down insights using interactive filters
